# Mapping evidence

Reviewed 2026-11-20.

[CIMA Bivair SmPC, sections 2 and 3](https://cima.aemps.es/cima/dochtml/ft/87927/FT_87927.html) confirms that each 2.5 mL single-dose ampoule contains 0.5 mg ipratropium bromide (as monohydrate) and 2.5 mg salbutamol (as sulfate), in a nebuliser solution. These correspond to 0.2 MG/ML ipratropium bromide and 1 MG/ML salbutamol, called albuterol in RxNorm.

The new 30-ampoule Bivair presentation (771377) has the same registration number and clinical formulation as the existing 20-ampoule presentation (757412). The source des_dosific lists ipratropium first, whereas des_dcp lists salbutamol first; the quantities match after respecting ingredient order.

Hecate standard RxNorm search confirms concept 43011917 (1362214), `albuterol 1 MG/ML / ipratropium bromide 0.2 MG/ML Inhalation Solution`, as an EXACT match. Pack count does not change the clinical concept. Existing exact mappings are retained.
