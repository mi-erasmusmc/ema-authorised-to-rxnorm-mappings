# Mapping sources

- [CIMA Aterina 25 mg SmPC](https://cima.aemps.es/cima/dochtml/ft/90202/FT_90202.html), section 2, checked 2026-11-09: each 25 mg capsule corresponds to 250 lipasemic units (ULS), supporting the RxNorm Extension 250 UNT Oral Capsule mapping. The separate anti-Xa activity is 2250 IU and is not the unit used by this concept.
