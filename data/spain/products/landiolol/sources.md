# Mapping evidence

Reviewed 2026-11-09.

- [AEMPS Rapibloc 300 mg SmPC](https://cima.aemps.es/cima/dochtml/ft/89271/FT_89271.html), section 2: 300 mg landiolol hydrochloride equals 280 mg landiolol. The vial is reconstituted for IV administration and used immediately after opening; unused solution is discarded. The same salt/base conversion is recorded in the repository weight_conversions.tsv.
- Hecate standard RxNorm search returned landiolol 280 MG Injection (1466068; 2712074), which matches the powder vial dose and single-use form. The US brand Rapiblyk is not used for Rapibloc. Extension Rapibloc Injectable Solution adds the brand but has a multidose form, so standard RxNorm is preferred.
