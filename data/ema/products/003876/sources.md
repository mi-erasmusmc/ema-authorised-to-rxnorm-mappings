# Vaxchora mapping evidence

Reviewed 2026-11-11.

- Local EMA footnote.txt specifies 400000000 to 2000000000 viable cells of live attenuated Vibrio cholerae CVD 103-HgR per dose. Both parsed files contain the same single authorisation number, EU/1/20/1423/001; these are duplicate descriptions of one presentation.
- [EMA product information](https://www.ema.europa.eu/en/documents/product-information/vaxchora-epar-product-information_en.pdf) describes active and buffer sachets and reconstitution using 100 mL water, with half the buffer solution discarded before adding active component for children aged 2 to under 6 years. The web search retrieved preparation instructions; direct PDF retrieval was rate-limited.
- [US prescribing information on DailyMed](https://dailymed.nlm.nih.gov/dailymed/lookup.cfm?setid=2d33d9ae-1fe6-477e-9285-8890f6e98be4) confirms the active/buffer packet presentation and age-dependent 100 mL or 50 mL final suspension. It lists RxCUI 1812951 for the 12000000 UNT/ML suspension.

Standard RxNorm search found reconstituted oral-suspension concepts. Extension search found clean branded concept 36943142, Vibrio cholerae live attenuated Powder for Oral Suspension [Vaxchora] (OMOP5199744). This preserves the supplied powder form. BROAD remains appropriate because explicit strain, potency range and the two-component presentation are absent. The suggestion uses the valid Powder for Oral Suspension dose form; the potency range is documented in the comment instead of inventing a fixed concentration.
