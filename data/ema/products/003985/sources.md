# Opdivo subcutaneous formulation

[EMA assessment report](https://www.ema.europa.eu/en/documents/variation-report/opdivo-h-c-003985-x-0144-epar-assessment-report-variation_en.pdf) explicitly describes nivolumab and rHuPH20 600 MG/10000 UNT per 5 ML (120 MG/2000 UNT per ML), single-use. Hyaluronidase is classified as an excipient in EU. [EMA product information](https://www.ema.europa.eu/en/documents/product-information/opdivo-epar-product-information_en.pdf) lists 300 MG/2.5 ML and 600 MG/5 ML SC single-use vials. [US Opdivo Qvantig label](https://dailymed.nlm.nih.gov/dailymed/fda/fdaDrugXsl.cfm?setid=7f8c38fa-42f4-4387-9e8c-7a1c66855d8b&type=display) treats the same hyaluronidase as active. Standard RxNorm volume-specific combination Injection concepts match these presentations; Qvantig is the US formulation suffix of the same Opdivo base brand. Corrected the prior 5 ML row that incorrectly used a multidose nivolumab-only solution; audit in flag.tsv.
