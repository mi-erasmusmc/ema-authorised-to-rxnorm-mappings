# Roctavian

- [EMA product information](https://www.ema.europa.eu/en/documents/product-information/roctavian-epar-product-information_en.pdf): each single-use vial contains 16 x 10^13 vector genomes in 8 mL, concentration 2 x 10^13 vg/mL.
- [DailyMed Roctavian label](https://dailymed.nlm.nih.gov/dailymed/lookup.cfm?setid=0dcf7185-8e1c-456a-9d4e-7cc316400118&version=18): the same Roctavian product is named valoctocogene roxaparvovec-rvox in the US, with the same concentration and 8 mL extractable volume.
