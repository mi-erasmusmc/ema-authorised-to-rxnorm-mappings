# Nezglyal

The local authorised-presentations PDF/TSV states 13.66 mg/mL. [Current EMA SmPC](https://www.ema.europa.eu/en/documents/product-information/nezglyal-epar-product-information_en.pdf), section 2, expresses this as 13.7 mg/mL leriglitazone (as hydrochloride), 1370 mg per 100 mL bottle. The suggestion follows the current rounded label concentration.

No matching strength/form concept was found in standard RxNorm or Extension. Extension provides the actual ingredient LERIGLITAZONE (36858814, OMOP5176431); map BROAD to that ingredient rather than use a different glitazone.
