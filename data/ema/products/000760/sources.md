# Silapo

[EMA overview](https://www.ema.europa.eu/en/medicines/human/EPAR/silapo) identifies epoetin zeta, biosimilar to Eprex/Erypo. The repository biosimilar reference does not link Silapo to FDA epoetin alfa-epbx. Each source presentation was inspected individually: 11 volume/concentration patterns across 48 syringes. Clean Extension epoetin-zeta concepts preserve each actual syringe; BROAD follows the no-FDA-equivalent biosimilar rule. Existing unsupported alfa-epbx mappings also collapsed different syringe doses to a 1 ML injection. Corrections recorded in flag.tsv.
