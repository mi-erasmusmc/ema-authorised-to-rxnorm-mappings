# Sources

- [EMA Tenofovir disoproxil Viatris product information](https://www.ema.europa.eu/en/documents/product-information/tenofovir-disoproxil-viatris-epar-product-information_en.pdf), reviewed 2026-11-06: each film-coated tablet contains 245 mg tenofovir disoproxil as maleate. All seven authorised presentations have the same dose and oral tablet form.
- [DailyMed tenofovir disoproxil fumarate label](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=a75c6be8-3719-4bb3-8a9e-06e5254d2a82), reviewed 2026-11-06: 300 mg tenofovir disoproxil fumarate is equivalent to 245 mg tenofovir disoproxil. Mapping normalizes the salt to the same active dose; it does not assert the source contains fumarate. The map-drugs weight_conversions.tsv also records 245 mg tenofovir disoproxil as equivalent to 300 mg maleate or 300 mg fumarate.
- Hecate searches on 2026-11-06 confirmed standard RxNorm concept 1710312, tenofovir disoproxil fumarate 300 MG Oral Tablet (RxCUI 349251). Extension searches for maleate and 245 mg disoproxil tablets returned no clean, correctly named salt-specific equivalent. Existing EXACT mappings retained; new pack sizes map to the same equivalent active-dose concept.
