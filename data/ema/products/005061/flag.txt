Folder contents were inconsistent before review: the local PDF and parsed TSV had been mislinked to Zimbus Breezhaler (EMEA/H/C/005518, EU/1/20/1440/*), while the EMA metadata for this folder is Enerzair Breezhaler (EMEA/H/C/005061, EU/1/20/1438/*). Parsed rows were corrected to match the EMA all-authorised-presentations table for Enerzair Breezhaler. The currently EMA-hosted `_hu.pdf` retrieved from the Enerzair all-authorised-presentations URL still embeds Zimbus Breezhaler metadata, so that binary PDF should not be treated as authoritative for this folder without independent cross-checking. EMA authorised presentation strengths are delivered doses: indacaterol 114 ug / glycopyrronium 46 ug / mometasone furoate 136 ug per capsule. Previously reviewed metered doses are indacaterol 150 ug / glycopyrronium 63 ug / mometasone furoate 160 ug per capsule. This delivered-versus-metered distinction is worth preserving because RxNorm inhalation concepts are not fully consistent on which basis they use. Standard RxNorm still lacks the full indacaterol/glycopyrronium/mometasone furoate triple combination, so rows are mapped BROAD to glycopyrronium / indacaterol Inhalation Powder with the full triple combination retained in suggestion.
